# Zenn Contents Repository Rules

このプロジェクトはZennの記事および本を管理するためのリポジトリです。
エージェントは以下のルールに従ってアシストを行ってください。

## 1. 記事・本の作成方法
- 新規記事を作成する際は、必ず `npx zenn new:article` コマンドを実行してファイルを生成してください。
- 新規本を作成する際は、必ず `npx zenn new:book` コマンドを実行してディレクトリとファイルを生成してください。

## 2. Markdownの記法 (Zenn Flavored Markdown)
Zenn独自のMarkdown拡張記法に準拠して記述・修正を行ってください。
- **メッセージ機能**: 補足や注意書きを記述する際は、`:::message` を使用してください。
  ```markdown
  :::message
  ここにメッセージを書きます
  :::
  ```
- **アラート機能**: 警告を記述する場合は `:::message alert` を使用します。
- **リンクカード**: 参考URLなどを記載する際は、インラインリンクではなく、URLを単独の行に配置してリンクカードにしてください（前後に空行を入れること）。外部サイトはスクレイピング拒否等で正しく表示されないことが多いため、**原則として本リポジトリ内の適切な既存記事への内部リンクのみ**を追加してください。
- **コードブロック**: コードブロックには言語名を指定し、必要に応じてファイル名も記述してください（例: ` ```python:main.py ` ）。
- **見出しの絵文字**: すべての見出し（`##` や `###`）に絵文字をつけると視覚的にノイズになり、記事の階層構造が分かりづらくなります。絵文字は **大見出し（`##`）のみに限定** し、小見出し（`###` 以降）にはつけない（テキストのみとする）ルールとします。

## 3. フロントマター (Frontmatter)の取り扱い
各Markdownファイルの先頭にあるYAMLフロントマター（`title`, `emoji`, `type`, `topics`, `published` など）は、Zennの仕様上必須です。
- 記事の本文を修正する際、ユーザーからの明確な指示がない限りフロントマターの設定は変更しないでください。
- **`topics`（タグ）は最大5つまで**しか設定できません。自動設定・追加時も必ず5つ以下に収めてください。

## 4. プレビューの確認
ユーザーが作成した記事の表示結果を確認したい場合などには、`npx zenn preview` を実行してローカル環境(`http://localhost:8000`)で確認するよう案内するか、適宜バックグラウンドで起動して確認作業の補助を行ってください。
